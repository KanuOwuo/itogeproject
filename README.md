## Описание
Book Tracker — простое GUI‑приложение для учёта прочитанных книг. Позволяет:
* добавлять книги с указанием названия, автора, жанра и количества страниц;
* фильтровать список по жанру и минимальному количеству страниц;
* сохранять данные в JSON‑файл;
* загружать сохранённые данные при запуске.

## Функциональность
* **Добавление книг** с валидацией ввода (проверка на пустые поля и число страниц).
* **Фильтрация** по жанру (частичное совпадение) и количеству страниц (минимум).
* **Сохранение/загрузка** данных в формате JSON (`books.json`).
* **Визуальное отображение** списка книг в таблице с возможностью прокрутки.

## Требования
* Python 3.6 или выше.
* Стандартные библиотеки Python: `tkinter`, `json`, `os` (установка не требуется).
